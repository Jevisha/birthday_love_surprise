# Birthday Love Surprise ❤️

A romantic, responsive birthday webpage inspired by the idea of a personalized birthday surprise.

## Quick start
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Replace the sample photos in `assets/photos/` with your own:
   - `photo1.jpg`
   - `photo2.jpg`
   - `photo3.jpg`
4. Put your music file at `assets/music/song.mp3`.
5. Edit the text directly in `index.html` to personalize names, memories and messages.

## GitHub Pages
Create a GitHub repository, upload all files while keeping the folder structure, then enable GitHub Pages from repository Settings → Pages → Deploy from branch.

## Notes
- No backend is required.
- The site is mobile-friendly.
- If the music does not autoplay, use the floating music button.
- The fallback images are remote Unsplash images only when local photos are missing; replace them with your own photos for a fully self-contained site.
